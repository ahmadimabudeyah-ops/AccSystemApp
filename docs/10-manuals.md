# المخرج 10: التوثيق النهائي (الفهرس الرئيسي)

## 1. دليل المبرمج
البنية: `backend/app/{models,services,api/v1,web,templates,static}` + `db/sql/phases`
+ `scripts/` (بذور/فحوصات/دورات). التسمية: snake_case عربي التعليق؛ Type Hints و
Docstrings إلزامية؛ Git: فرع لكل وحدة + مراجعة + CI (pytest + check_pages).
أفضل الممارسات: لا كتابة أستاذ إلا عبر `PostingService`؛ كل حدث بمفتاح؛ RLS أولًا.

## 2. دليل المستخدم (حسب الوحدة)
الدخول (رمز المؤسسة + بريد) → لوحة (أرقام حية) → دليل/شجرة → قيد (أسطر متوازنة
→ ترحيل بمعتمد آخر) → فواتير (إنشاء→ترحيل→تحصيل→تخصيص) → مشتريات مماثلة →
خزينة/أصول/رواتب/رسوم/مشاريع → تقارير (فترة→عرض→طباعة/CSV) → إعدادات/تدقيق.
كل شاشة: عنوان + Breadcrumbs + إجراء واضح + حالة فارغة صادقة.

## 3. دليل المدير والصيانة
المدير: أدوار (13) وصلاحيات، فترات (إقفال/فتح باعتماد)، سياسات، نسخ احتياطي.
الصيانة: الأعطال الشائعة (400 بلا مستأجر، 403 فصل مهام/تزوير، 409 فترة/تجاوز)،
إعادة البناء (`phases` بالترتيب + `fix_*`)، الأسئلة المتكررة، المشكلات المعروفة:
(أ) أرقام تسلسلية يدوية للمستندات غير القيود (عدادات `doc_sequences` تغطيها)؛
(ب) JoFotara طابور محلي بلا إرسال حقيقي (يحتاج مفاتيح الإنتاج).
