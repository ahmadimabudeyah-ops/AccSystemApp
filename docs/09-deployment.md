# المخرج 9: النشر والتشغيل (محلي الآن → سحابي لاحقًا)

## 1. البيئات
- **Dev/QA (الحالية):** Python venv + PostgreSQL محلي (5433 نسخة المشروع) + `python wsgi.py`.
- **Staging:** نسخة بيانات مجهولة + نفس السكربتات + اختبارات كاملة قبل كل ترقية.
- **Production:** `FLASK_ENV=production` + مفاتيح ≥32 بايت + `waitress` (Windows) أو `gunicorn` + TLS + `pg_basebackup` مجدول. خطة رجوع: استعادة PITR لآخر نقطة + إعادة تشغيل الحزمة السابقة (ترحيلات Alembic قابلة للعكس).

## 2. التشغيل والطوارئ
- مراقبة: سجلات منظمة (`audit` + أخطاء) → Prometheus/Grafana مرحلة 2؛ تنبيه فشل نسخ/طابور JoFotara.
- صيانة: ترحيلات نسخ-أولًا، بذور idempotent، `scripts/check_pages.py` دخان ما بعد النشر.
- طوارئ: RPO ≤ 24س (WAL أقل)، RTO ≤ 4س؛ استجابة: عزل → استعادة → مطابقة أرصدة → تقرير.
