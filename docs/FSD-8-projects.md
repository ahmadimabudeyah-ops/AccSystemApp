# FSD-8: المشاريع والموازنات والتجميع

## 1. المشاريع
مشروع (موازنة/عميل/حالة) + مراحل/مهام + تكاليف/إيرادات مرتبطة بقيود +
مستخلصات واحتجاز + أوامر تغيير + هامش محسوب (إيراد−تكلفة). القاعدة: لا تكلفة
بلا مستند مصدر (قيد/فاتورة).

## 2. الموازنات
موازنة/سنة (مسودة→معتمدة→نشطة) + بنود UQ(موازنة،حساب) + مناقلات بموافقة +
التزامات + انحراف = مخطط − فعلي (الفعلي من مرحّل سنة الموازنة). الإصدارات
تحفظ التاريخ ولا تعيد كتابته.

## 3. التجميع (مرحلة 2)
تشغيل (مجموعة/فترة) + استبعاد البيئية + تسعير بيئي موثق + حقوق غير مسيطرين +
فروق ترجمة العملات. المبدأ: ترجمة ثم استبعاد ثم تجميع بقيد تجميع مستقل.

## 4. مصفوفة الترحيل (مشاريع/موازنات)

| الحدث | مدين | دائن |
|---|---|---|
| قيد تكلفة مشروع | مصروف المشروع | نقدية/ذمم (حسب المصدر) |
| مستخلص معتمد | عميل المشروع | إيراد المشروع |
| احتجاز مستخلص | عميل | احتجاز دائن |

## 5. القواعد والاختبارات (JR001–JR80 / JT01–JT25)

JR010 المناقلة لا تتجاوز المتاح وتتطلب اعتمادًا؛ JR020 الفعلي يُقرأ من المرحّل
فقط؛ JT05 انحراف = مخطط − فعلي لثلاثة بنود؛ JT10 تجميع يستبعد البيئية بالكامل.
