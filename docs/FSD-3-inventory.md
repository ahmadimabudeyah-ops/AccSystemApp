# FSD-3: المخزون والتكلفة

## 1. النطاق
أصناف (مخزني/خدمي/مستهلك/مجموعة) + وحدات وتحويلات + مستودعات/مواقع هرمية +
حركات (استلام/تسليم/داخلي/تسوية/تالف/مرتجع/تصنيع/عبور) + حجوزات + دفعات/تسلسلات
+ صلاحية (FEFO) + جرد فعلي/دوري + تحويلات + تالف + تكاليف إضافية (شحن/تأمين/
جمارك توزع قيمة/كمية/وزنًا).

## 2. التقييم
- المتوسط المرجح (افتراضي JO): طبقة واحدة متحركة عند كل استلام مسعّر.
- FIFO: طبقات تُستهلك بالأقدم (جداول valuation جاهزة).
- المعياري: فرق السعر في حساب مخصص. المحدد: للمسلسل.
- القاعدة: لا مخزون سالب (رفض)، والتكلفة المفقودة = آخر سعر موثق.

## 3. مصفوفة الترحيل

| الحدث | مدين | دائن |
|---|---|---|
| استلام شراء | مخزون 1310 | مورد/GRNI |
| تسليم بيع | COGS 5010 | مخزون |
| تالف معتمد | مصروف تالف | مخزون |
| عجز/فائض جرد | عجز/مخزون | مخزون/فائض |
| تكاليف إضافية | مخزون (+تكلفة الوحدة) | مورد الشحن |

## 4. القواعد والاختبارات (IR001–IR80 / IT01–IT30)

IR010 الحركة المنتهية خالدة؛ IR020 الحجز لا يتجاوز المتاح؛ IR030 الدفعة
منتهية الصلاحية محظورة الصرف؛ IT05 استلام يرفع المتوسط حسابيًا؛ IT10 صرف
يفوق المتاح مرفوض؛ IT20 الجرد يولد قيود الفروق.
