# FSD-6: الرواتب والموارد البشرية (أردني)

## 1. النطاق
موظفون (ضمان/بنك/بدلات) + عقود + هياكل/مكونات + مسيرات شهرية + قسائم
(استحقاق/استقطاع/كلفة صاحب عمل) + ضمان 7.5% موظف / 14.25% صاحب عمل +
ضريبة دخل تصاعدية من شرائح جدولية (إعفاء سنوي 9000 قابل للضبط) +
سلف تُخصم تلقائيًا بحد المتبقي + إجازات + حضور/ورديات (أساس) + نهاية خدمة.

## 3. القواعد والاختبارات (HR001–HR60 / HT01–HT25)

المتبقي → يُخفض تلقائيًا؛ HR030 لا ترحيل في فترة مغلقة؛ HT05 صافي = إجمالي −
ضمان − ضريبة − سلفة (حالة أردنية حقيقية)؛ HT10 ترحيل مكرر بنفس المفتاح → 200.
