# المخرج 6: خطة التنفيذ (12 شهرًا — Agile/Scrum، Sprint أسبوعان)

## المنهجية
Scrum: تخطيط/يومي 15د/مراجعة/رجعي. Definition of Done = كود + اختبارات خضراء +
توثيق + مراجعة. البيئات: Dev → QA → Prod. الأدوات: Git + CI (اختبارات + فحص
مخطط) + لوحة مهام.

- أداء التقارير → لقطات لا مسح حي. الفريق: 2 خلفية + 1 واجهة + 1 جودة + محلل/محاسب جزئي.
