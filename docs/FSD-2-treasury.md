# FSD-2: الخزينة والبنوك

## 1. النطاق
صناديق (رصيد حي = افتتاحي + مقبول مرحّل − مدفوع مرحّل)، سندات قبض/صرف بترقيم
CT متسلسل، تحويلات داخلية برقم TR، شيكات (صادرة/واردة/مؤجلة: issued/cashed/
bounced/cancelled/deferred)، بنوك وحسابات IBAN، عهد، نقد قيد التحويل.

## 2. التدفق المحاسبي
كل حركة نقدية = مستند + قيد مسودة (نقدية ↔ حساب مقابل صريح) + ترحيل بفصل مهام.
التحويل = قيد من حساب المصدر إلى حساب الهدف. الشيك المُحصّل = بنك مدين / شيكات
برسم التحصيل دائنة (تُبنى مرحلة 2؛ حاليًا تتبع حالات + ترحيل يدوي).

## 3. مصفوفة الترحيل

| الحدث | مدين | دائن |
|---|---|---|
| قبض نقدي | صندوق 101001 | عميل/إيراد (الحساب المقابل) |
| صرف نقدي | المصروف/المورد | صندوق |
| تحويل داخلي | حساب الهدف | حساب المصدر |
| تحصيل شيك | بنك | شيكات برسم التحصيل |

## 4. المطابقة البنكية (مرحلة 2)
استيراد كشف (CSV/MT940) → مطابقة آلية (مبلغ+تاريخ±3 أيام) → فروق يدوية →
تقرير مطابقة مجمد. القواعد TR001–TR80 والاختبارات TT01–TT25 في الملحق، ومنها:
TR010 لا صرف بلا رصيد صندوق كافٍ (تحذير)، TR020 الشيك المرتد يعكس التحصيل
بقيد، TR030 التحويل بين عملتين بسعر يومه مع فرق صرف مستقل.
