# FSD-4: الأصول الثابتة وغير الملموسة

## 1. النطاق
فئات (عمر/طريقة) + إضافة (كلفة/متبقٍ/موقع) + إهلاك شهري مرحّل + تحويلات +
إعادة تقييم/انخفاض + بيع/استبعاد + أعمال تحت التنفيذ (CIP تُرسمل عند الإنجاز)
+ غير ملموسة (إطفاء خطي).

## 2. طرق الإهلاك
- القسط الثابت: (كلفة−متبقٍ)/العمر شهريًا.
- المتناقص: صافي الدفتر × (2/العمر)/12. يتوقف عند المتبقي تلقائيًا
  (`fully_depreciated`). القيد: مصروف إهلاك 5130 مدين / مجمع 1519 دائن.

## 3. مصفوفة الترحيل

| الحدث | مدين | دائن |
|---|---|---|
| إهلاك شهري | 5130 | 1519 |
| استبعاد | مجمع + خسارة/مقبوضات | الأصل (بالكلفة) + ربح |
| إعادة تقييم (فائض) | الأصل | احتياطي إعادة تقييم |

## 4. القواعد والاختبارات (AR001–AR60 / AT01–AT20)

AR010 لا إهلاك بعد الاكتمال؛ AR020 الاستبعاد يتطلب تصفير الصافي؛ AR030 مطابقة
سجل الأصول مع الأستاذ شهريًا (تقرير). AT05 إهلاك مكرر لنفس الشهر مرفوض
(مفتاح حدث)، AT10 بيع بأقل من الصافي = خسارة محسوبة.
