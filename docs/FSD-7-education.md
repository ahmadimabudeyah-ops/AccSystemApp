# FSD-7: التعليم

## 1. النطاق
طلاب (+طرف) + أولياء (+طرف، مسؤول مالي) + تسجيل + عقود رسوم (صافي بعد خصم،
UQ طالب/عام) + أقساط (مستحقة/مدفوعة/جزئية) + تحصيل (تخصيص تلقائي + قيد) +
خصومات/منح (تخفض الصافي) + استرداد/انسحاب/نقل + أنشطة/نقل مدرسي/كتب/علامات/
حضور/امتحانات (أساس، تتوسع مرحلة 2).

## 3. القواعد والاختبارات (ER001–ER60 / ET01–ET20)

ER010 العقد الفعال واحد للطالب/العام؛ ER020 الدفعة لا تتجاوز متبقي القسط؛
ER030 التحصيل يحدث الحالة تلقائيًا (جزئي/مدفوع)؛ ET05 عقد بخصم 10% على 3000 =
2700 صافي؛ ET10 تحصيل زائد مرفوض 409.
