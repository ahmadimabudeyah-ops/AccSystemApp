# المخرج 7: وثيقة الأمان التقني

## 1. المصادقة
JWT قصير (15د) + تحديث (7 أيام، قابل للإلغاء عبر user_sessions+jti)؛ كلمات
bcrypt (تكلفة 12 إنتاجًا) بطول ≥8 وتعقيد؛ MFA TOTP للأدوار المالية (جداول جاهزة)؛
سياسة إغلاق بعد 5 محاولات فاشلة (login_attempts).

## 2. التفويض والعزل
RBAC (13 دورًا، مصفوفة في `seed_rbac.py`) + نطاق كيان في `user_roles`؛ مطابقة
مستأجر JWT/Header (403)؛ RLS + FORCE على كل جدول مستأجر بمفتاح جلسة، وفشل مغلق؛
حساسية الأعمدة (IBAN/رواتب) تُقرأ بصلاحية فقط (تعمية مرحلة 2)؛ TLS 1.3 إجباري.

## 3. التدقيق والحماية
`audit_logs` إلحاقي (بلا UPDATE/DELETE حتى للمالك) يسجل الفاعل/الفعل/الكيان/
قبل/بعد/IP لكل: ترحيل/عكس/اعتماد/إقفال/مستخدم/تحصيل. الحماية: استعلامات
مُعامِلة (لا حقن)، تحقق Pydantic-نمط لكل مدخل، CSRF للنماذج (توكن)، تحديد معدل
(مرحلة 2)، رؤوس أمان إنتاجية.

## 4. النسخ والامتثال
يومي كامل + WAL مستمر + PITR (30 يومًا) + اختبار استعادة أسبوعي + نسختان
جغرافيتان + AES-256. الامتثال: OWASP Top 10 مُغطى تصميمًا؛ القوانين الأردنية
مرجعية دون ادعاء؛ البيانات الشخصية (وطني/ضمان) بأقل صلاحية.
